# DMV_CSO_INVESTMENT_VIZ

Ireland’s Capital Shift: Tangible vs. Intangible Investment & Output Distortion (1995–2026)

📊 Data Sources

Data is fetched directly from the central statistics office (CSO). 
We are using NAQ10 & NAQ03 datsets.
NAQ10: Querterly Gross Fixed Capital Formation by Asset Type
NAQ3: Querterly Gross Domestic Product (GDP) and Gross National Product (GNP)

📈 Key Visual Features

Single Explanatory Combo Graph: Combines a 100% stacked area breakdown of capital investment shares (Left Y-Axis) with overlaid intangible-to-GDP and intangible-to-GNP ratio lines (Right Y-Axis).

Price-Basis Toggle: Switch dynamically between Current Prices (€ Million) and Constant Volumes (Real).

Contextual Annotations & Range Slider: Highlights key multinational balance-sheet shocks (e.g., 2015 IP onshoring and 2019 IP/aircraft leasing surges) alongside interactive time-window zooming.
